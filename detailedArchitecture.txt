- Client Socket Connection Procedure:

+ Client -> Server
+ Asking the server to exchange it Public Key
+ Format: {"Message Code": "#0000"}


Server -> Client
+ Ensure Client message is strictly == {"Message Code": "#0000"}
+ If not:
    + Format: {"Message Code": "#0000", "Status Code": 400, "Error": Bad Request Error}
Else:
    + Format: {"Message Code": "#0000", "Status Code": 200, "Server Public Key": ServerPU}


+ Client -> Server
+ If status code == 400:
    + Display Critical Pop-up Window Notify Bad Request Error
    + Quit Application
+ If status code == 200:
    + Checking the SHA512 hash of the server public key against the pre-shared hashed
    + If not match:
        + Display Critical Pop-up Window Notify A Potential Man-In-The-Middle attack due to server public key verification failure
        + Quit Application
    + Else:
        + Accept the server PU
+ Asking the server to verify the client current source code
+ Obtain the SHA512 of the current client source code
+ Obtain the current client temp PU
+ Sign the HashedClientCode:ClientTempPU
+ Message: {"Message Code": "#0001", "Client Message: HashedClientCode:ClientTempPU, "Client Digital Signature": ClientSignature}
+ Randomly Generate AES key
+ AES-256 encrypt the message
+ Encrypt the AES-256 key with the server PU to obtain shared secret
+ Send SharedSecret:EncryptedPayload


+ Server -> Client
+ Check for client format to be exactly SharedSecret:EncryptedPayload
+ If Failed:
    + Sign "Bad Request Error"
    + Send Message: {"Status Code": 400, "Server Message": "Bad Request Error", "Server Digital Signature": serverSignature}
+ Else:
    + Attempt decrypt the shared secret with the server private key
    + If Decryption Failure:
        + Sign "Server Can Not Decrypt the client-sent data"
        + Send Message: {"Status Code": 500, "Server Message": "Server Can Not Decrypt the client-sent data", "Server Digital Signature": serverSignature}
    + Else:
        + Execute "Message Code" == "#0001" branch:
            + Obtain Client Temp PU and source code hash
            + Store Client Temp PU temporary for future communication with the client
            + Verify client signature with the newly obtained client Temp PU
            + If Verified:
                + Check if hashed source code matched
                + If hash matched:
                    + Sign "Client Source Code Verification Success"
                    + Message: {"Message Code": "#0001",  "Status Code": 200, "Server Message": "Client Source Code Verification Success", "Server Digital Signature": "serverSignature"}
                    + Hybrid Encrypt the message to obtain shareSecret and cipherText
                    + Send shareSecret:cipherText
                + Else:
                    + Obtain Correct Client source code from the server storage
                    + Obtain the SHA-512 hash
                    + Sign SourceCode:hash
                    + Message: {"Message Code": "#0001", "Status Code": 202, "Server Message": "{clientSourceBytes}:{hashedClientSourceCode}", "Server Digital Signature": "{serverSignature}"}
                    + Hybrid Encrypt the message to obtain shareSecret and cipherText
                    + Send shareSecret:cipherText
            + Else:
                + Sign "Server Can Not Verify Client Digital Signature"
                + Send Message: {"Status Code": 501, "Server Message": "Server Can Not Verify Client Digital Signature", "Server Digital Signature": serverSignature}


+ Client -> Server
+ Check if server message a valid json dict
+ If True:
    + Check server signature:
    + If Good:
        + Check for all possible Status Code and inform user
    + Else:
        + Inform user about server digital signature verification failure
    + Quit Application
+ Else:
    + Check server message shareSecret:encryptedData
    + If True:
        + Attempt hybrid decrypt
        + If Success:
            + Check server signature:
            + If Good:
                + Execute Message Code == "#0001" branch:
                    + If Status Code == 200:
                        + Launch authentication form interface
                        + Proceed to authentication procedure
                    + If Status Code == 202:
                        + Display an Information Pop-Up Window notify "Your current client source code does not match the server version. In order to continue, do you want to download the correct version?"
                        + If No:
                            + Tell user need to update to continue connection
                        + Else:
                            +  Download the source code
                            +  Verify the download
                            + If failed:
                                + Display a Critical Pop-Up Window notify "Download Verification Failure"
                            + Else:
                                + Display a Notification Pop-Up Window notify "Download Success, please replace your source code with the downloaded version!"
                        + Quit Application
            + Else:
                + Inform user about server digital signature verification failure
                + Quit Application
        + Else:
            + Display a Critical Pop-Up Window notify Client Can Not Decrypt Server Data
            + Quit Application
    + Else:
        + Display a Critical Pop-Up Window notify Client Can Not Decrypt Server Data
        + Quit Application

                + Check if client username already registered
                + If Registed:
                    + Check if account is currently locked:
                    + If Not:
                        + Verify the password hash
                        + If match:
                            + Sign "Authentication Success!"
                            + Message: {"Message Code": "#0002", "Status Code": 200, "Server Message": "Authentication Success!", "Server Digital Signature": serverSignature}
                        + else:
                            + Check if current allow failed attempt < 0:
                            + If True:
                                + Set account lock to 3hr
                                + Update account lock history
                                + Sign "Too Many Invalid Log In Attempt!\nAccount is locked for 3 hr!"
                                + Message: {"Message Code": "#0002", "Status Code": 401, "Server Message": "Too Many Invalid Log In Attempt!\nAccount is locked for 3 hr!", "Server Digital Signature": serverSignature}
                            + Else:
                                + Decrement the current allow failed login attempt by 1
                                + Sign "Invalid Credential Provided! You have currnetLogInAttempt remaining"
                                + Message: {"Message Code": "#0002", "Status Code": 401, "Server Message": "Invalid Credential Provided! You have currnetLogInAttempt remaining", "Server Digital Signature": serverSignature}
                    + Else:
                        + Sign "Your account is currently locked for {hr}:{min}{sec}"
                        + Message: {"Message Code": "#0002", "Status Code": 403, "Server Message": "Your account is currently locked for {hr}:{min}{sec}", "Server Digital Signature": serverSignature}
                + Else:
                    + Sign "There is no registered account with user name userName yet!"
                    + Message: {"Message Code": "#0002", "Status Code": 401, "Server Message": "There is no registered account with the user name 'userName' yet!", "Server Digital Signature": serverSignature}
                + Hybrid Encrypt the message to obtain shareSecret and cipherText
                + Send shareSecret:cipherText
        + Else:
            + Sign "Server Can Not Verify Client Digital Signature"
            + Send Message: {"Status Code": 501, "Server Message": "Server Can Not Verify Client Digital Signature", "Server Digital Signature": serverSignature}

                    + Elif "Message Code" == 401:

                                + Quit Application

                                + Sign "clientUserName:hashsed:clientPU"
                                + Message: {"Message Code": "#0003", "Client Message": "clientUserName:hashsed:clientPU", "Client Digital Signature": "ClientSignature"}
                                + Hybrid Encrypt the message to obtain shareSecret and cipherText
                                + Send shareSecret:cipherText
                    + Elif "Message Code" == 403:
                        + Display server message in the form
                        + Locked Form
                        + Wait two second
                        + Quit Application
            + Else:

- Client sent a message to a friend

+ Client -> Server
+ Sign Message with Permanent PI -> senderSignature
+ Message now {"Message": message, "Sender Signature": senderSignature}
+ Generate random AES-256 key, Encrypt Message with the AES-256 key -> EncryptedMessage
+ Encrypt AES-256 key with client permanent PU -> keyForSelf
+ Encrypt AES-256 key with the recipient permanent PU -> keyForRecipient
+ finalMessage = {"To": recipient, "Date": date, "Message": EncryptedMessage, "Key For Self": keyForSelf, "Key For Recipient": keyForRecipient}
+ Sign finalMessage with temp PI -> clientSignature
+ finalMessageToServer = {"Message Code": "#0006", "Client Message": finalMessage, "Client Digital Signature": clientSignature}
+ serverHybridEncrypt(finalMessageToServer) -> sharedSecret, encryptedMessage
+ Send sharedSecret:encryptedMessage to server

+ Server Received
+ Check for client format to be exactly SharedSecret:EncryptedPayload
+ If Failed:
    + Sign "Bad Request Error"
    + Send Message: {"Status Code": 400, "Server Message": "Bad Request Error", "Server Digital Signature": serverSignature}
+ Else:
    + Attempt decrypt the shared secret with the server private key
    + If Decryption Failure:
        + Sign "Server Can Not Decrypt the client-sent data"
        + Send Message: {"Status Code": 500, "Server Message": "Server Can Not Decrypt the client-sent data", "Server Digital Signature": serverSignature}
    + Else:
        + If Message Code == "#0006" branch:
            + clientMsg = {"To": recipient, "Date": date, "Message": EncryptedMessage, "Key For Self": keyForSelf, "Key For Recipient": keyForRecipient}
            + Store clientMsg in the client and recipient encrypted chat history list
            + Obtain the recipient username
            + Check if recipient is currently online and interacting with sender:
            + If True:
               + Sign clientMsg with server PI
               + {"Message Code": "#0006", "Status Code": 200, "Server Message": clientMsg, "Server Digital Signature": serverSignature}
               + Encrypt and send recipient
            + Else:
               + Update the pending unread message from client on the recipient
            + Sign "Message Deliver Success!" with serverPI
            + {"Message Code": "#0006", "Status Code": 200, "Server Message": "Message Deliver Success!", "Server Digital Signature": serverSignature}
            + Encrypt and send to the message author
